# 镜湖森境岛屿设计规格

## 目标

以 `origin-island.json` 为唯一原始数据，设计一套森系、强中轴、自然微差的可游玩岛屿方案。最终同时交付 `design/01.json` 与从该 JSON 在应用中加载后导出的 `design/01.png`。

## 固定约束

- 保留 `version: "v2"` 和 `112 × 96` 坐标系。
- 服务处/广场保持 `amenities_townhallSprite: [53, 66]`，码头保持 `amenities_dock: [104, 84]`。
- 原始机场、河流入海口、海岸线、码头、半岛、秘密海滩和沿岸礁石不得移动。
- 新设计只修改内部地形、水系、道路、可移动建筑和植被；所有区域必须可步行到达。

## 空间构图

全岛以 `x = 56` 为视觉中轴。南部由机场方向通过四格宽泥土林荫主路连接固定服务处，主轴继续向北抵达镜湖。服务处自身略偏离中轴的误差，通过两侧等量绿化和路径留白吸收。

北部中央设置镜湖和湖心森林岛，左右各布置一条瀑布及下游溪流，并连接原始河口。湖区两侧建立镜像二级高地，最北端设置成对三级松林观景台。南部入口保持平坦，桥梁和坡道成对设置，不阻断主轴。

## 建筑与道路

- 玩家住宅位于北部中轴高地，作为主轴视觉终点。
- 十栋居民住宅组成五对，分散在东西两侧林苑，位置镜像、庭院细节微差。
- 博物馆与商店分居东西两侧并保持等量占地；服装店与露营地通过庭院补齐体量差异。
- 主轴使用 `pathDirt`，镜湖、桥头与服务处周边少量使用 `pathStone`；两格宽支路组成闭合步行环线，不设置死路。
- 木桥跨越有效河道，木坡道只连接相邻高度，建筑前保留完整出入口和操作空间。

## 森系植被

高地以松树为主，低地混合阔叶树、少量果树和竹林。树木总体左右成对，但允许一至两格的局部错位。花色限制为白、绿、黄色，搭配三叶草、蒲公英、灌木和香蒲表现自然林下层。入口与服务处周边控制密度，北部和外缘形成更浓密的森林包围感。

## 验证与交付

生成后校验 JSON 可解析、固定对象坐标未变、原始外边界和河口端点未变、建筑不重叠且左右主要元素成对。随后在应用中加载 `design/01.json`，等待异步图片完成，使用内置地图保存流程导出 PNG，并确认 PNG 非空、完整显示岛屿、与 JSON 对应且没有加载占位图或界面遮挡。
